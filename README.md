# Vigil Status Page

A lightweight, self-hosted status page and monitoring tool for my homelab infrastructure. 

## Features
- Container health monitoring
- Minimal resource footprint
- Fully deployed via Docker Compose

## Prerequisites
- Docker & Docker Compose
- A reverse proxy (e.g., Traefik or Nginx Proxy Manager) configured for your domain.
